

### ⚙️ 期货马丁格尔策略核心参数卡

| 参数名称 | 建议值 | 设计逻辑与说明 |
| :--- | :--- | :--- |
| **杠杆倍数** | **2倍** | 风险与效率的平衡点。既能提升资金效率，又不会因一次普通回调就爆仓。**这是你策略的安全基石，不建议提高。** |
| **首单保证金** | **10 USDT** | 占总资金（2000U）的 **0.5%** ，非常安全，为后续补仓留出巨大空间。 |
| **加仓倍数** | **1.5倍** | 这是控制风险的核心。用温和加仓代替翻倍加仓，防止资金在连续下跌中过快耗尽。 |
| **价格补仓间隔** | **0.8%** （均匀间隔） | 按价格跌幅触发，与杠杆无关。在BTC正常波动下能提供足够的交易机会。 |
| **单轮最大补仓次数** | **7~8次** | 主动限制，为账户保留充足缓冲资金（约1200~1500U），防止黑天鹅。 |
| **整体止盈目标** | **2%~3%** | 覆盖杠杆下的手续费和资金费率成本，同时保证在反弹时能快速锁定利润。 |
| **硬止损（总账户）** | **总亏损达20%~30%** | **这是你整个策略的“保险丝”**。一旦触发，无条件平掉所有仓位，保住剩余本金。 |
| **趋势风控** | **上涨≥5%时暂停新开仓** | 防止在单边上涨中持续追高，等待价格回落或横盘后再重新入场。 |
| **交易对** | **BTC/USDT 永续合约** | 流动性最好，深度最佳，滑点最小。 |

### ✅ 策略执行要点

1.  **用限价挂单实现自动补仓**：提前在 59,520、59,044、58,572... 等价位挂好限价买单，无需盯盘。
2.  **循环功能谨慎使用**：建议先手动完成几轮完整的“建仓→补仓→止盈”，确认参数安全后再开启自动循环。
3.  **每日检查资金费率**：如果市场资金费率长期为正且较高，需要适当提高止盈目标（如从2%提到2.5%），以覆盖持仓成本。
4.  **定期复盘**：每周统计一次实际交易次数、手续费占比、资金费率支出，根据数据微调参数（如将0.8%间隔调整为1.0%）。

> **这个策略的成功，不取决于你“对方向的判断”，而取决于你对“万一判断失误”这个风险的管理。**

杠杆放大的不仅是收益，也是你的贪婪和恐惧。严格遵守上面这套参数，尤其是**硬止损**和**最大补仓次数**，你就能在“震荡上行”的预期下，安全地让资金转起来。
